# Checklist de entrega — Asistente IA de WhatsApp (D1-D7)

> Para el checklist del cliente (se marca durante la entrega). Los hitos de cobro:
> 50% firma → 30% demo funcionando → 20% entrega (ver 05-PRODUCTOS.md).

## Día 1 — Base
- [ ] Número de WhatsApp del cliente verificado (Cloud API oficial)
- [ ] Webhook conectado y probado (ping-pong real: el cliente recibe respuesta)
- [ ] Esquema Supabase creado (contactos, conversaciones, leads)

## Día 2-3 — Guion (el 80% del valor)
- [ ] 10-20 FAQs REALES del cliente recolectadas (en la venta/demo)
- [ ] Prompt maestro personalizado (prompts/prompt-maestro.md)
- [ ] Catálogo/precios reales cargados (sin inventar nada)
- [ ] Derivación a humano configurada (con resumen de conversación)
- [ ] Captura de leads funcionando (nombre + teléfono → Supabase)

## Día 4 — Pruebas
- [ ] 10 preguntas de prueba end-to-end (las reales del cliente)
- [ ] Prueba de horario fuera de servicio (mensaje nocturno)
- [ ] Prueba de derivación (petición fuera de alcance → llega al humano)
- [ ] Correcciones del prompt aplicadas

## Día 5 — Entrega
- [ ] Capacitación 30 min al dueño/equipo (cómo se ve el panel, cómo se hacen cambios)
- [ ] Reporte semanal explicado (qué incluye y cuándo llega)
- [ ] Garantía y soporte 30 días por escrito
- [ ] Primer retainer cobrado por adelantado (regla de caja)
- [ ] 3 referidos pedidos (regla del sistema de ventas)

## Día 6-7 — Soporte
- [ ] Monitoreo de conversaciones reales (primeras 48h)
- [ ] Ajustes finos del prompt con preguntas reales
- [ ] Primer reporte semanal entregado al dueño
